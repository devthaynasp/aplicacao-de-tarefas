# 📝 Aplicação de Tarefas

> Um projeto simples, mas muito importante na minha jornada como desenvolvedora 💻✨

---

## 🚀 Sobre

Essa aplicação foi desenvolvida com o objetivo de praticar conceitos fundamentais do React na prática.

Durante o desenvolvimento, trabalhei com gerenciamento de estado, rotas e persistência de dados, construindo uma aplicação funcional de lista de tarefas.

Esse projeto representa uma etapa importante da minha evolução como desenvolvedora front-end 🚀

---

## 🧠 O que eu aprendi

* ✔ Criar e organizar componentes em React
* ✔ Utilizar Context API para estado global
* ✔ Trabalhar com React Router (navegação entre páginas)
* ✔ Usar hooks como useState e useEffect
* ✔ Salvar dados no localStorage
* ✔ Implementar um CRUD completo

---

## 🛠️ Tecnologias

* ⚛️ React
* 🔀 React Router DOM
* 💻 JavaScript
* 🎨 HTML + CSS

---

## ⚙️ Funcionalidades

* ➕ Adicionar tarefas
* 📝 Editar tarefas
* ❌ Excluir tarefas
* 📋 Listar tarefas
* 💾 Persistência com localStorage

---

## ▶️ Como rodar

```bash
git clone https://github.com/DEvthaysp/aplicacao-de-tarefas
cd aplicacao-de-tarefas
npm install
npm start
```
